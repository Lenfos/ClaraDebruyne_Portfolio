## 🇫🇷 Version Française

### 💄 Clara Debruyne – Portfolio de Maquilleuse Professionnelle

Bienvenue sur le dépôt du **portfolio de Clara Debruyne**, maquilleuse professionnelle basée en France. Ce site a été conçu pour présenter ses réalisations artistiques dans les domaines du maquillage beauté, artistique, événementiel et studio.


🔗 [clara-debruyne.fr](https://clara-debruyne.fr)


### 🛠️ Technologies utilisées

- **HTML5 / CSS3**
- **JavaScript (Vanilla)**
- **Figma**
- **Vercel**

### ✨ Fonctionnalités

- Galerie dynamique des maquillages réalisés
- Effets de transition doux et animations au scroll
- Design responsive (mobile, tablette, ordinateur)
- Contact pour prise de rendez-vous ou collaboration

### 📁 Structure du projet

```bash
ClaraDebruyne_Portfolio/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   └── fonts/
└── ...
```

### 🚀 Lancer le projet en local

```bash
git clone https://github.com/Lenfos/ClaraDebruyne_Portfolio.git
cd ClaraDebruyne_Portfolio
```

Ouvrez `index.html` dans votre navigateur.

### 👩‍🎨 À propos de Clara

Clara est une **maquilleuse professionnelle passionnée**, spécialisée dans le maquillage beauté, artistique et événementiel. Elle propose ses services en studio, en déplacement ou en collaboration avec des photographes, vidéastes et stylistes.
